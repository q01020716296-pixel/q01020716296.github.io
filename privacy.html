개인정보처리방침

시행일: 2026년 9월 30일

PickBox Product Scout(이하 "픽박스")는 해외 상품 트렌드 조사, 상품 후보 관리 및 소싱 분석을 지원하는 데스크톱 프로그램입니다. 본 개인정보처리방침은 픽박스의 이용과 관련하여 처리될 수 있는 정보와 그 이용 목적, 관리 방법을 안내합니다.

1. 처리하는 정보

픽박스는 사용자가 이용하는 기능에 따라 다음과 같은 정보를 처리할 수 있습니다.

  • 사용자가 입력한 상품명, 검색어 및 카테고리
  • 상품 URL, 가격, 매입 비용, 배송비 및 예상 수익 정보
  • 사용자가 작성한 메모, 조사 기록 및 상품 후보 정보
  • 사용자가 가져오거나 내보내는 CSV 파일의 정보
  • 외부 플랫폼 연동 시 해당 플랫폼의 승인된 권한 범위에서 조회하는 데이터
  • 외부 API 연동에 필요한 인증 및 연결 정보

위 항목은 프로그램의 기능과 사용 방식에 따른 처리 가능 정보이며, 모든 항목을 항상 수집하거나 외부 서버로 전송한다는 의미는 아닙니다.

2. 정보의 이용 목적

처리되는 정보는 다음 목적에 이용될 수 있습니다.

  • 상품 후보의 등록, 조회, 수정 및 관리
  • 해외 상품 트렌드 및 검색어 조사
  • 상품 비교 및 소싱 후보 분석
  • 매입가, 판매가, 배송비 및 예상 마진 계산
  • 사용자가 요청한 외부 플랫폼 데이터 연동
  • 프로그램 오류 확인 및 기능 개선

3. 정보의 저장 및 보유 기간

상품 정보와 조사 기록은 프로그램의 로컬 데이터베이스 또는 사용자가 선택한 파일에 저장될 수 있습니다. 실제 저장 위치와 보유 기간은 사용 중인 버전과 기능의 구현 방식에 따라 달라질 수 있습니다.

외부 API 인증정보의 저장 여부, 저장 위치 및 보호 방식은 실제 연동 기능의 구현 상태에 따릅니다. 인증정보를 저장하거나 외부 서버에 전송하는 기능이 활성화된 경우, 해당 기능의 안내와 설정을 확인해야 합니다.

본 프로그램 운영자는 실제로 처리하지 않는 정보를 수집하거나 보유한다고 전제하지 않습니다.

4. 외부 서비스와 데이터 이용

사용자가 Google Trends, Pinterest 또는 기타 외부 플랫폼의 자료 조회 기능을 이용하는 경우, 해당 서비스가 제공하는 공개 자료나 승인된 API를 통해 정보를 조회할 수 있습니다.

외부 서비스에 전달되는 요청 정보와 조회 가능한 데이터는 각 플랫폼의 기능, 이용약관, API 권한 및 사용자의 설정에 따라 달라집니다.

외부 플랫폼이 자체적으로 처리하는 개인정보에는 해당 플랫폼의 개인정보처리방침과 이용약관이 적용됩니다. 픽박스는 외부 플랫폼과 별도의 제휴 관계가 있음을 의미하지 않습니다.

5. 개인정보의 제3자 제공

픽박스 운영자는 이용자의 개인정보를 임의로 판매하거나 제3자에게 제공하는 것을 목적으로 하지 않습니다.

다만 사용자가 외부 플랫폼 연동 기능을 직접 사용하는 경우, 기능 작동에 필요한 요청 정보가 해당 플랫폼에 전달될 수 있습니다. 법령에 따른 의무가 발생하는 경우에는 관련 법률에 따릅니다.

6. 정보의 보호 및 인증정보 관리

사용자는 자신의 계정 정보, API 키 및 인증 토큰을 안전하게 관리해야 합니다. 인증정보를 공개 저장소, 공개 웹페이지 또는 타인에게 노출하지 않도록 주의해야 합니다.

픽박스의 구체적인 인증정보 저장 방식과 보안 조치는 실제 배포 버전의 구현 및 설정에 따릅니다. 확인되지 않은 암호화, 접근 통제 또는 보안 기능이 제공된다고 보장하지 않습니다.

7. 정보의 열람, 수정 및 삭제

사용자는 프로그램에서 제공하는 기능을 통해 저장된 상품 정보와 조사 기록을 관리할 수 있습니다. 개별 항목 삭제 및 전체 데이터 삭제의 지원 여부는 사용 중인 프로그램 버전의 기능에 따릅니다.

로컬 데이터베이스 파일이나 저장 자료를 직접 삭제하기 전에 필요한 정보를 백업하는 것이 좋습니다. 외부 플랫폼의 연결 권한은 해당 플랫폼의 계정 설정에서 확인하거나 철회할 수 있습니다.
